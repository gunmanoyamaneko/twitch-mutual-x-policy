# X Developer Portal 用の公開ページ

このフォルダーをGitHubリポジトリへ置き、GitHub Pagesで公開する。

GitHub Pagesの公開元をこのフォルダーに設定できない場合は、フォルダー内の内容を公開用リポジトリのルートへコピーする。

公開URLが `https://<account>.github.io/<repository>/` の場合、X Developer Portalには次を設定する。

- ウェブサイトURL: `https://<account>.github.io/<repository>/`
- 利用規約: `https://<account>.github.io/<repository>/terms/`
- プライバシーポリシー: `https://<account>.github.io/<repository>/privacy/`

X APIの利用方法または実際のデータ保存方法を変更した場合は、利用規約とプライバシーポリシーも更新する。
